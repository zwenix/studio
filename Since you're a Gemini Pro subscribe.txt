Since you're a Gemini Pro subscriber (specifically through the Google One AI Premium plan), you actually have a distinct advantage: you receive monthly Google Cloud credits (typically $10–$100 depending on your tier) that can be applied toward using Gemini in your developer projects.

To use your subscription's power in a Firebase app, you should use Firebase AI Logic (formerly known as Vertex AI for Firebase). This is the official way to call Gemini directly from your mobile or web app securely.
+1

1. Setup the Infrastructure
To link your subscription credits to your project, your Firebase project must be on the Blaze (Pay-as-you-go) plan. Don't worry—the credits from your Gemini Pro subscription will automatically offset the costs of your API calls.

Go to the Firebase Console.

Select your project and upgrade to the Blaze Plan if you haven't already.

In the left sidebar, navigate to Build > AI Logic.

Click Get Started to enable the required APIs (Vertex AI and Gemini).

2. Integration (Web/JavaScript Example)
Firebase provides a specialized SDK that handles the security proxying for you, so you don't have to expose an API key in your frontend code.

Install the SDK
Bash
npm install firebase
Initialize and Call the Model
Here is how you would set it up in your app code:

JavaScript
import { initializeApp } from "firebase/app";
import { getVertexAI, getGenerativeModel } from "firebase/vertexai";

// Your Firebase configuration
const firebaseConfig = {
  // ... your config from Firebase Console
};

// Initialize Firebase
const app = initializeApp(firebaseConfig);

// Initialize the Vertex AI service (Firebase AI Logic)
const vertexAI = getVertexAI(app);

// Use 'gemini-2.5-pro' or 'gemini-3.1-pro-preview' 
// for the most advanced reasoning
const model = getGenerativeModel(vertexAI, { model: "gemini-2.5-pro" });

async function runPrompt() {
  const prompt = "Write a tagline for my new DevOps tool.";
  const result = await model.generateContent(prompt);
  console.log(result.response.text());
}
3. Secure Your API with App Check
Since you are calling the API directly from the client, anyone who has your app could technically "steal" your subscription's quota.

Action: Enable Firebase App Check in the Firebase Console.

Why: This ensures that only your actual app (signed by you) can make requests to Gemini, preventing unauthorized users from draining your credits.
