# 📂 Classroom Templates Folder

Place your static HTML templates, PDFs, or images in this folder.

### How to use:
1. Drop your `.html` or `.pdf` files here.
2. When you deploy, they will be available at:
   `https://studio-4710648038-f5ed1.web.app/templates/your-file-name.html`
3. Copy that URL and paste it into the **"Remote Document URL"** field in the Template Store.

This method is recommended for large files to avoid browser upload timeouts.
